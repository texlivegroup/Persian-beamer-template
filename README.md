# قالب ارائه Beamer فارسی 
Persian Beamer Presentation Template

 یک قالب آماده و حرفه‌ای برای ارائه‌های علمی، دانشگاهی و کنفرانسی به **زبان فارسی** با استفاده از **Beamer** و **XeLaTeX**
 |
 A complete Persian RTL template for academic and professional presentations using Beamer and XeLaTeX

---

## 📌 نمای کلی | Overview

این مخزن شامل یک قالب کامل **Beamer** برای نوشتن ارائه‌های راست‌به‌چپ (RTL) به زبان فارسی است. با استفاده از این قالب می‌توانید به سادگی اسلایدهای زیبا، استاندارد و علمی برای کنفرانس‌ها، سمینارها و جلسات دفاع پایان‌نامه تولید کنید.

---

## ✨ ویژگی‌ها | Features

- ✅ پشتیبانی کامل از نوشتار **راست‌به‌چپ (RTL)*ستفاده از بسته 
- ✅ سازگار با xelatex**
- ✅  دارای فونت Yas
- ✅ ساختار آماده برای: صفحه عنوان، فهرست مطالب،  رنگ‌ها، فونت‌ها و استایل
- ✅ خروجی PDF با کیفیت بالا
- ✅ کاملاً رایگان و متن‌باز (مجوز MIT)
